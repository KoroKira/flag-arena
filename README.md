# Flag Arena 196

Application mobile pour départager 196 drapeaux en 19 110 duels uniques.

## Installation iPhone

Activer GitHub Pages dans Settings → Pages → Deploy from a branch → main / root. Ouvrir ensuite https://korokira.github.io/flag-arena/ dans Safari, puis Partager → Sur l'écran d'accueil.

Les votes sont enregistrés dans le stockage local de ce navigateur/appareil. Exporter régulièrement une sauvegarde JSON ; l'import permet de reprendre après un changement d'appareil. Les drapeaux sont affichés avec les emoji Unicode du système.
